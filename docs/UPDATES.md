# 在线更新与版本回退

网络优化与版本操作互斥。升级保留显式优化选择；回退到 0.18 或更早版本时，HY2 使用旧版本自身策略，系统 BBR 与 UDP 缓冲保持当前值。重新升级到 0.19 后恢复所保存的 HY2 选择。

0.17.0 起，管理员可以点击左上角版本徽标打开 **版本与更新**。Lite 和 Pro 面板均支持，当前页面只管理本机版本。轻量业务站没有管理员网页，可由服务器管理员使用相同升级脚本维护；不会随主控更新自动升级全部业务站。

## 检测与选择更新

1. 点击 **检查更新**，读取本项目 GitHub 的正式 Release。草稿、预发布和没有对应 Lite / Pro 安装包的版本不列出。
2. 紧凑卡片显示当前版本、最新版本和新版本提示。点击 **立即更新** 选择最新正式版本；也可展开 **选择版本与回退**，选择具体版本并点击 **更新到所选版本**。
3. 核对版本后点击 **确认更新**。检查更新本身不会安装，也不会定时自动安装。
4. 后台下载并校验外层 SHA256、包内文件清单、版本与版本类型，以及固定代理核心。随后停服务、备份、切换版本、准备配置并验证服务健康。
5. 面板短暂断开时页面继续重连。确认目标版本已健康运行后开始 **8 秒倒计时**，自动刷新当前页面；不会在固定等待时间结束但服务仍异常时盲目刷新。

版本目录缓存 15 分钟；手动检查之间至少间隔 60 秒，避免反复访问 GitHub。无法连接版本来源时显示错误并保留已有目录，不把网络故障当作最新版本。下载临时文件在操作结束后清理。发行来源是本项目 GitHub，不能在网页指定任意下载 URL 或执行 shell 命令。

这是后台升级与自动重连，不是进程内无中断代码替换。代理核心可能短暂重启，客户端需要自动重连。旧面板或浏览器页面在更新期间保持打开即可；关闭页面不取消服务器上的操作，重新打开会恢复显示进度。

## 回退范围

**不能回退到安装基线之前。** 新安装把该安装包版本记为基线；升级不会改变它。旧部署在第一次启用此功能时，以升级前正在运行的版本建立基线。这是保守下限，不会推测缺失的更早安装历史。

基线保存在 root 专属的 `/var/lib/guangyue-updater/installation.json`，与面板数据库、面板程序和它们的回退快照分离。网页提交、直接调用 API、普通升级脚本和回退操作均检查下限。服务器 root 管理员有操作系统的最终控制权；此约束不声称能阻止 root 手工替换软件或删除所有安装记录。

回退列表显示最多 30 个已安装且具有本机备份的旧版本，目标必须：

- 不低于安装基线，且低于当前版本。
- 属于相同 Lite / Pro 类型、站点身份和部署角色。
- 与当前数据库迁移清单及校验值兼容。

**手动版本回退保留当前账号、订阅、配置和流量数据库。** 它只切换程序、前端和匹配服务定义。数据库不兼容的版本会被禁用，服务器也会拒绝请求；不会为了满足回退自动恢复几天前的用户或计费数据。准备配置或健康检查失败时，会恢复此次操作开始前的完整快照。

若回退到 0.16.0 等没有版本入口的旧面板，在线更新按钮随旧前端消失；独立更新服务、安装基线和历史继续保留。可通过 SSH 使用下面的受校验安装包升级命令回到新版。回退本身不会删除离线备份，磁盘不足时拒绝开始新操作。

## 安装与运维

标准安装与 `deploy/upgrade.py` 自动配置按需启动的本机 Unix socket 更新服务。主面板仍为 `guangyue` 非 root 用户；执行器只监听 `/run/guangyue-update.sock`，不开放公网管理端口。只有本站管理员可以通过面板访问，成员及独立面板联邦令牌不能执行更新。

- `/opt/guangyue-updater/`：独立执行器，回退旧面板时保留。
- `/var/lib/guangyue-updater/`：root 专属安装基线、版本目录、操作与回退记录。
- `/root/guangyue-backups/upgrade-*/`：完整升级前快照，含应用、配置、状态和 PostgreSQL dump（适用时）。
- `guangyue-updater.socket` / `guangyue-updater.service`：按需启动，空闲约两分钟后退出释放内存；开机检查未完成操作的恢复记录。

迁移服务器时同时备份更新记录、匹配离线备份、面板状态与配置。不要只复制数据库后把旧版本当作新安装来重建下限。删除某个升级备份后对应回退选项不再可用；请保留至少最近一次已知可用备份。

```bash
sudo systemctl status guangyue-updater.socket guangyue-updater.service
sudo python3 /opt/guangyue-updater/update_agent.py status
# 从正式 Release 获取、验证并解压所选安装包后：
sudo python3 /opt/guangyue-updater/update_agent.py install-bundle /root/guangyue-panel-pro-0.17.0-linux-amd64
# 仅允许列表中兼容且不低于基线的旧版本：
sudo python3 /opt/guangyue-updater/update_agent.py rollback 0.16.0
```

示例回退版本不意味着所有安装都允许回退到它；首次安装 0.17.0 的服务器会拒绝 0.16.0。执行器本身不修改 Nginx 虚拟主机、现有域名或证书布局。原有 Certbot 续期钩子保留，升级与证书部署共用互斥锁。

源码开发环境或非标准目录安装会显示在线更新服务不可用，可继续按既有命令行部署方式维护。执行器暂不提供 Docker 镜像更新、跨架构迁移、强制数据库降级或批量业务站升级。
