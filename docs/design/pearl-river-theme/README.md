# ip.minminlove.top Blue Theme

This package is the current Pearl River Night blue theme loaded by
`https://ip.minminlove.top` on 2026-10-11.

## Files

- `assets/pearl-river-theme.css` - the visual theme stylesheet.
- `design/pearl-river-night.png` - the theme background.
- `design/moon-seal-theme.svg` - the blue theme brand mark.
- `manifest.json` - source URLs, sizes, and SHA-256 checksums.

## Deploy

Copy the two directories into the site public directory, preserving these
paths. The application entry page must load:

```html
<link rel="stylesheet" href="/assets/pearl-river-theme.css">
```

The stylesheet references `/design/pearl-river-night.png` and
`/design/moon-seal-theme.svg`.
