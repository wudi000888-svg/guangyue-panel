# 架构与设计边界

## 组成

Go 后端提供 REST API、会话鉴权、SQLite WAL 状态、AES-GCM 凭证保存、配置生成和有限后台任务。Vue 3 前端作为静态文件随应用发布。没有额外数据库或队列进程。

代理面包括 Xray VLESS Reality/Vision、带节点路由补丁的单实例 HY2，以及按需启动的 Mihomo 上游桥接。多个用户、多个逻辑节点共用核心进程，避免每个出口启动一套面板。Nginx 根据 SNI 转发 TCP 443；HY2 直接接收 UDP 443。

## 数据与授权

用户角色为 owner/user。会话、协议权限、有效期和总配额在服务端验证。私有池与公共池的节点和订阅分别授权，成员响应移除出口密码和上游敏感配置。

AES-GCM 的主密钥与数据库保存在同一受限状态目录，可以降低单独泄露数据库的风险，但不能防御整个服务器或完整备份被读取。密码使用 bcrypt；生产仍需要保护 root、SSH、备份和订阅令牌。

来源归属独立保存：一个来源删除时清理其独占出口与绑定节点；共享资源继续由其他来源拥有。默认直连节点受保护，不作为可删除 IP 池资源。

## HY2 补丁

[补丁说明](../core-patches/README.md)记录固定上游 commit、构建方法和测试。鉴权成功后按不可变逻辑节点选择出口，未知节点拒绝连接；TCP 流和 UDP 报文使用同一路由。协议握手、TLS、QUIC 和拥塞控制继承 Hysteria 上游实现。

路由变更会重启共享 HY2 服务，导致短暂重连。用户撤销使用鉴权与连接踢出流程。不能替换为未打补丁的官方 HY2 二进制，否则无法正确保证节点出口隔离；面板会校验构建标记。

## 资源预算

SQLite 单连接；来源更新错峰且串行；测速、质量与公共采集有并发/超时/数量预算。缓存保留查询时间和来源，黑名单减少重复失败探测。默认减少无界探测和重复进程，但不能保证任意资源规模在固定内存中运行。

## 明确边界

- 单 VPS；没有跨服务器控制、HA、组织隔离、计费、SSO 或 SLA。
- DNS 防护覆盖被代理流量，不覆盖客户端绕过代理的独立 DNS、IPv6 或直连应用。
- 数据源可能失效、限流或冲突；“未知”是有效结果，不伪造住宅/原生/解锁标签。
- 公共代理为可选资源，与业务出口分离；它的来源和转发方不由本项目控制。
- 流量统计为运营信息，重启与轮询存在边界，不用于严格财务结算。
- 备份恢复处理可检测 I/O 错误，但不承诺跨文件断电原子性。
- 非 root 服务与 cgroup 限额降低影响范围，不是容器级不可信租户沙箱。
