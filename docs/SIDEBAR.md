# 调整侧边栏入口

管理员打开「系统设置 → 更多功能」，可把功能拖到左侧侧边栏，也可把侧边栏中不常用的入口拖回功能目录或底部「更多功能」。手机和键盘操作可使用「放入侧边栏」「移到更多功能」按钮。在「侧边栏配置」中勾选、取消或恢复默认，同样立即生效并自动保存。拖拽调整当前站点的管理员侧边栏；成员入口由管理员切换至「成员侧边栏」统一配置，成员没有个人拖拽配置权限。「设置」固定保留，收起入口不会关闭功能或改变访问权限。

界面先显示调整结果，再显示自动保存进度和服务器确认状态。请求失败时会重新读取服务器，已实际保存的操作会得到确认；未保存或仍无法确认的改动恢复到已确认入口，并提供重试。只需等待「侧边栏已自动保存」，无需再点击保存按钮。站点信息、注册及下载与访问等其他设置仍需手动保存，调整侧边栏不会提交这些未保存的草稿。

导航配置仅更新当前站点所选角色的入口，管理员和成员两套配置可并发保存而不相互覆盖；切换远程子站后，之前站点的响应不会写入新站点的界面。其他设置保存时会合并最新导航配置；如果另一位管理员同时修改了站点信息或访问规则等非导航字段，仍会提示冲突并要求重新加载，避免覆盖对方修改。
