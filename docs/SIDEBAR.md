# 把常用功能放到侧边栏

侧边栏只保留常用入口，其余功能集中在 **系统设置 → 更多功能**。收起入口不会停用功能、删除数据或改变权限。

## 调整入口

管理员可以直接：

- 从“更多功能”拖动手柄到侧边栏，立即显示该入口。
- 将侧边栏入口拖回“更多功能”目录或底部收纳区域，立即收起。
- 在手机或使用键盘时，点击 **放入侧边栏／移到更多功能**，得到同样结果。
- 在 **侧边栏配置** 勾选、取消或恢复默认。

这些操作自动保存，不需要另点保存按钮。等待 **侧边栏已自动保存** 代表服务器已确认。**设置** 入口固定保留，公共功能还受“公共功能显示”偏好限制，Pro 功能仍受版本及角色限制。

管理员侧边栏与成员侧边栏分别配置。要改变成员看到的入口，切到 **成员侧边栏**；成员不能自行拖拽改变本站配置。

## 保存失败或多人操作

界面先响应调整，再显示保存进度。请求失败时重新读取服务器：已保存的结果会得到确认，未保存或无法确认的改动恢复到已确认配置，并提供重试。

两种角色的导航可分别保存，不互相覆盖。切换远程子站后，之前站点的响应不会写入新站点。导航自动保存也不会提交品牌、注册、访问规则等未保存草稿；**这些设置仍需手动保存**。若其他管理员同时修改非导航设置，页面会提示重新加载以避免覆盖。
