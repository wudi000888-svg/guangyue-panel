# 使用手册

## 角色与导航

`owner` 是管理员，可管理全部资源与成员。普通 `user` 只能访问自己的订阅、节点质量信息和站内信等授权内容，不能看到出口凭证或其他用户订阅。

顶部可切换中文/English、主题、简易/专业模式。简易模式集中展示私有 IP 池、节点、用户等核心工作；专业模式展示公共 IP 池、采集来源和更多运行策略。**界面模式只改变导航，不是权限隔离，也不会停止后台任务。**

常规/无日志在运行设置中单独控制；与界面模式互不影响。切到简易模式前，需要停用公共采集时请先到专业模式关闭采集开关。

### 手机与平板

窄屏使用单行顶栏，语言切换常驻；点击右上角“显示与账户”设置简易/专业模式、主题、密码或退出。左上角打开完整抽屉导航；底部常用导航按账号权限显示。更新入口位于抽屉品牌下方。

节点与私有出口在手机上采用卡片和共用分页，顶部可选择全部当前筛选结果；保护默认直连节点的规则仍生效。用户、业务站、独立面板和任务以字段卡片显示，复杂表格可在表格内部横向滚动。

## 推荐首次配置顺序

1. 修改初始管理员密码；在系统设置填写面板名称、组织、支持邮箱与登录提示。
2. 在用户管理创建成员，设置协议开关、到期时间、总流量配额和启用状态。
3. 检查节点管理中的默认 VLESS / HY2 直连节点。它们代表服务器本机出口，不显示在私有 IP 池中。
4. 在私有 IP 池添加业务出口，测速和检测质量后，绑定为新的 VLESS 或 HY2 节点。
5. 用成员账号打开“私有订阅”，复制订阅到客户端，分别验证直连和外部出口。
6. 有需求时再启用专业模式的公共采集；公共节点与业务私有订阅始终分开。

## 用户管理

密码从 1 位起，无复杂度要求；不能留空，最多 72 个 UTF-8 字节（ASCII 字符 1 字节、常见汉字 3 字节）。创建、重设和自助改密规则一致。编辑成员时密码留空表示保持原密码。修改密码后原登录会话失效，需要重新登录。

- 有效期为空/0 表示不限时，配额为 0 表示不设配额；以界面显示单位为准。
- VLESS/HY2 分别授权；总流量配额按用户共享，不是每节点独立配额。
- 禁用、到期或用尽配额后停止授权；流量轮询存在有限延迟，不是金融级实时计费。
- 重置流量只重置统计周期；不要与订阅轮换混淆。
- 私有订阅、公有订阅有独立令牌。撤销泄露订阅应轮换对应令牌；撤销节点凭证使用对应撤销操作。
- 保管管理员密码；当前不支持企业 SSO、细粒度 RBAC 或多个隔离组织。

## 私有 IP 池

私有池包含三个视图：**订阅出口、独立出口、订阅来源**。顶部“添加 IP 资源”和“导入订阅/节点”常驻，切换子页不影响添加入口。

### 添加独立出口

选择 HTTP 或 SOCKS5，填写服务器地址、端口及可选用户名/密码，保存后执行检测。HTTP 表示 HTTP CONNECT 代理，并不表示连接代理服务器的一段自动具备 TLS；不要把这种链路当成端到端加密。

文件批量导入支持普通文本代理清单，例如：

```text
203.0.113.10:8080:demo_user:replace_this_password
203.0.113.11:1080:demo_user:replace_this_password
```

以上是文档保留网段与示例凭证，不可用于真实连接。可参考 [示例文件](../examples/proxies.txt)。导入时选择正确协议；对带分隔符的复杂凭证建议使用界面逐项填写或 URL 编码的节点链接。

### 导入订阅或单节点

输入你有权使用的 HTTP(S) 订阅地址，也可以粘贴单节点分享链接或上传文本文件。支持常见 Raw/Base64 URI 列表、Mihomo/Clash 配置和 Shadowrocket 导出的节点变体。协议支持取决于解析器与 Mihomo 兼容范围，并非任何客户端的私有格式都可导入。

常见 VLESS、VMess、Trojan、SS、SOCKS、HTTP、Hysteria 2 节点可用作上游。Shadowrocket 的 Base64 authority、remarks、peer、pbk、sid 等字段会规范化为上游配置。导入后查看接受/跳过数量与原因，先抽样测速，再绑定业务节点。

导入 URL 是秘密：通常含订阅令牌，禁止公开放入 issue、截图或示例。节点名称并不能证明出口位置，要实际检测出站 IP。

### 订阅来源管理

来源显示最近更新、下次计划、错误与资源数量。默认约每日更新一次，错峰执行，重型操作串行避免资源拥塞。可手动更新或删除。

删除来源会删除**只由该来源拥有的出口和对应绑定节点**，不会把它们转成独立出口；仍被其他来源引用的共享资源保留。更新移除的资源按其归属处理。操作前确认正在使用这些节点的成员会受到影响。

### 绑定和删除

选择出口创建 VLESS 或 HY2 新节点，不修改受保护的默认直连节点。支持多选批量操作；删除独立出口会级联删除绑定节点。订阅随之更新，客户端需要刷新。HY2 路由变化会重启共享核心，其他 HY2 连接可能短暂重连。

## 节点管理与 Reality

节点名称检测成功后按国家和出口 IP 生成，失败时保留可见检测状态。两种协议可绑定同一出口，各有独立链接与权限。

VLESS 的 Reality SNI 是与伪装目标进行 TLS 握手使用的主机名，必须与服务端目标兼容。默认继承全局 SNI，可在每节点指定并验证新目标。不能只改订阅 SNI 而不改服务端。不要使用本站域名、内网地址或不兼容目标。

创建/修改节点后查看应用状态；同步失败时先处理错误，不要把“保存成功”当成代理核心已经可用。

## DNS、IPv4 和 IPv6

每个节点可以选择 DNS 策略及 IPv6 策略。安全模式使用配置的 DoH 经该节点出口解析并限制不应直连的 DNS 路径。IPv6 出口不支持时选择阻断，支持时再启用并实测。

该保护只覆盖进入此节点的流量。客户端需要正确配置 TUN/全局代理、DNS 劫持或远程 DNS，关闭与策略冲突的浏览器独立 DoH；本面板无法阻止其他程序绕过代理直接联网。没有 IPv6 的 HTTP/SOCKS 上游不能凭面板开关变成双栈出口。

## 订阅、链接与二维码

私有和公共订阅分开显示，选择 Raw、Base64 或 Mihomo 格式。每张节点卡片包含对应的分享链接、复制按钮、二维码和质量报告入口。二维码等价于凭证，不能发到公开群或工单。

Shadowrocket、Mihomo 等客户端导入后，核对 Reality 参数与 HY2 支持情况。客户端版本不同，具体菜单和支持字段可能有差异；使用兼容的新版本。成员只应收到自己的订阅，不要共享管理员订阅。

## 质量检测和测速

标签按数据来源和时间展示：地理/ASN、数据中心或 ISP、代理/VPN/Tor、风险分数、注册与定位一致性，以及流媒体/AI 页面探测。信息缺失显示未知，多方不一致显示冲突；“注册与定位一致”不等于已经证明原生或家宽。

测速会消耗 VPS 和上游流量。节点测速检查对应链路，IP 池测速检查出口资源；延迟不是持续下载速度。一次成功不保证长期稳定，结合采样时间、路径和业务目标判断。

## 公共 IP 池（专业模式）

公开来源、采集策略、公共出口、公共节点与公共订阅分开管理。可导入来源、手动抓取或定时运行，配置并发、超时、速度/延迟阈值、数量上限。不可达代理进入黑名单/冷却逻辑，减少重复检测。不要把黑名单当作全球永久失效判定。

启用前先设置资源预算。建议小规模运行，观察仪表盘和系统内存再扩大。公共代理可能不稳定或记录流量，不适合作为登录、支付、商家账号和客户数据的默认出口。关闭采集后检查现有公共节点状态，按业务需要清理。

## 站内信和设置

管理员可向指定成员发送站内信；成员查看和标记已读。系统设置管理显示品牌、默认语言等；运行设置控制记录策略。无日志模式不是匿名保证：用户、配额、订阅状态、必要业务数据仍保存在数据库，上游代理、Nginx 外部配置和系统层也可能有自己的记录。

## 常见问题

- 订阅为空：核对用户是否启用、到期、配额、协议权限和节点启用状态。
- 出口错误：确认选中的是绑定新节点，客户端已刷新订阅且没有选默认直连。
- 只显示 IP 无国家：外部地理数据源不可用或还未检测，稍后重测。
- 私有订阅里有公共节点：应分别检查订阅 URL 和客户端缓存，两个池使用不同令牌；异常请脱敏报告。
- 删除后客户端仍看到节点：客户端保留旧订阅缓存，手动更新；服务端权限以当前状态为准。
- 保存设置后网络短暂断开：核心配置/路由变更可能触发重启；详见运维文档。
