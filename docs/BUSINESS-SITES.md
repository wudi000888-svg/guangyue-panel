# Pro 子站管理与调度

把子站生成的令牌粘贴到 Pro，便可在一个列表中管理多个面板。无需注册文件、预先创建分组或重装子站。子站保留自己的账号、节点、订阅、数据库和本地管理员，也可继续独立运行。

**远程管理、节点挂载和 IP 桥接是三个不同动作**：导入令牌建立管理连接；挂载将子站真实节点提供给主站套餐用户；IP 桥接则由主站中转，使用子站出口。后两种路径见[节点挂载指南](NODE_MOUNTS.md)。

## 连接一个子站

1. 按[安装指南](INSTALL.md)部署 Lite 或 Pro。Lite 可独立运营并生成本站令牌；Pro 可导入令牌管理子站。
2. 子站管理员打开 **配对令牌 → 生成子站令牌**，选择永久有效或 1–365 天期限。
3. 在 Pro 的 **群站管理 → 导入子站令牌** 粘贴完整 `gys_` 令牌，可附备注名称。
4. 连接后点击子站的用户、节点或监控入口。页面顶部显示正在管理的站点，点击 **返回本站** 退出远程上下文。
5. 如要让主站套餐使用子站节点，另到 **子站节点** 勾选并保存挂载；管理连接本身不等于节点已分发。

主站最多接入 64 个子站，重复导入更新已有连接。新令牌包含 HTTPS 根地址、凭据和实例身份；历史 `gyp_` 管理令牌需要补填根地址。不同服务器可使用相同显示用 `site_id`，实例身份用于隔离；不要复制整套数据库和密钥来创建“新”站点。

主站必须能访问子站公网 HTTPS。网关校验证书和目标身份，不接受跳过 TLS 校验、重定向或内网目标；本地回环例外仅用于开发测试。

## 管理员可以做什么

| 操作 | 作用范围 |
| --- | --- |
| 用户与套餐 | 管理目标子站的成员和套餐权益，按其本地规则应用权限 |
| 节点与出口 | 配置目标站节点、出口和默认倍率；固定节点组按来源维护 |
| 检测与任务 | 发起质量检测、测速等任务，结果在子站任务中心显示 |
| 暂停／恢复服务 | 暂停代理授权并撤回已有连接；保留账号和数据，恢复后按原权限运行 |
| 监控 | 查看目标站连接与流量快照；未知/过期数据不会显示为已确认的零 |
| 版本管理 | 查看安装版本、检测正式可用版本，提交子站更新或兼容回退并跟踪进度 |
| 移除连接 | 停止主站持有和使用该管理连接，保留子站软件与本地数据 |

目录约每 15 秒刷新，最多 4 个并发探测。在线连接与速率使用子站约 5 秒采样，累计用量来自持久计量。不同子站的同名用户不会自动合并；统一主站用户的节点挂载另建隔离代理身份。

版本操作需要管理令牌和子站支持对应更新接口。检测以正式 Release、完整资产及子站更新器校验为准，源码版本号或未完成发布不等于可安装版本。回退仅提供子站确认兼容的候选，不能绕过数据库边界。服务重启期间短暂断联时，页面继续核对原任务；**结束本地等待不等于取消远端更新**。

## 子站保留哪些控制权

子站管理员可以本地登录、恢复暂停的服务、限制令牌共享范围、撤销令牌或继续独立运营。撤销令牌使主站后续请求失效；移除管理连接不会自动恢复此前暂停的服务。

主站暂时断网不会让子站自己的本地用户失去权益。主站挂载用户则受短期授权租约约束，断联超过租约后撤回相应外来身份，详见[挂载权限](NODE_MOUNTS.md#权限与独立运营)。暂停整个子站服务会影响该站所有代理用户，但不禁止面板登录。

首次令牌接管默认关闭子站支付模块；子站管理员可以在本地明确重新启用。备份、密码、站内信、资金业务和配对令牌在子站本地管理，远程网关不转发这些入口，不提供递归站点转发或主密钥导出。

本版本不提供自动跨站负载均衡或故障切换。管理令牌不是站点私有数据备份，永久令牌也不是永不撤销的授权。

## 历史连接与迁移

以下说明用于升级现有部署，不是新安装步骤：

- 原“独立面板接入”记录进入统一子站列表，迁移只改变主站目录，不自行重启远端或替换远端数据。
- 拉取式业务站仍在同一列表，通过权限调度维护。移除后隐藏，未结算的用量与预留保留至最终确认。
- 旧业务站升级后可生成新令牌转为本地数据管理；转换保留最后有效权限，停止旧策略拉取，并受控重启应用。
- 历史只读令牌保持只读，不能用于调度或版本操作。完整新接口需要双方使用支持该功能的版本。

拉取协议及迁移差异见[历史业务站说明](BUSINESS-SITES-LEGACY.md)。备份子站要保留数据库、完整状态目录（含 `site-local.json`）、配置和匹配密钥。更新与回退见[版本说明](EDITIONS.md)和[运维指南](OPERATIONS.md)。
