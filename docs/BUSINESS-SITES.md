# Pro 子站管理与调度

0.24.0 使用“子站生成令牌 → Pro 粘贴导入”的连接方式。每个站点保留自己的账号、节点、订阅、数据库和本地管理员。Pro 只有一个子站列表，接入不需要注册文件、分组、预建站点或重新安装。

## 连接步骤

1. 按[安装指南](INSTALL.md)安装 Lite 或 Pro。Lite 默认独立运行，Pro 默认可管理其他站点。
2. 子站登录后打开 **配对令牌 → 生成子站令牌**，选择永久有效或 1～365 天。
3. 复制完整 `gys_` 令牌，在 Pro 的 **群站管理 → 导入子站令牌** 粘贴；可选填备注名称。
4. 连接成功后，直接使用 **用户、节点、监控、暂停服务／恢复服务**。顶部显示当前子站，点击“返回本站”回到主站。

新令牌包含子站 HTTPS 地址、凭据和站点身份。旧 `gyp_` 管理令牌仍可导入，只需补填子站 HTTPS 根地址。每个主站最多接入 64 个子站；重复导入更新已有连接。不同服务器可使用默认 `site_id`，新版本通过持久化实例身份区分；不要克隆整套数据库和密钥来新建站点。

主站需要能访问子站 HTTPS 地址。TLS 证书必须受信任；不接受重定向、内网地址或跳过证书校验。开发模式的本地回环地址例外只用于测试。

## 可调度内容

| 操作 | 行为 |
| --- | --- |
| 用户和权限 | 在目标子站创建或编辑成员，修改协议、有效期、额度、套餐和节点访问权限 |
| 节点和出口 | 在目标子站配置本机节点、出口、节点组和倍率；沿用其资源限制 |
| 远程检测 | 发起质量检测、测速及已有任务，进度在子站任务中心显示 |
| 暂停／恢复 | 暂停代理授权并排队断开现有连接，保留账号和原权限；恢复按原权限运行 |
| 流量和在线状态 | 列表每约 15 秒检测，最多 4 个并发；单站监控展示每用户连接和流量趋势 |
| 移除连接 | 在线或离线都可立即移除，主站不再持有该连接；子站数据与软件保留 |

暂停不会禁止面板登录。子站管理员可以在本地“配对令牌”页面独立恢复服务；撤销令牌后主站的后续访问立即失效。移除连接不会自动恢复此前暂停的服务，需要子站管理员按需恢复。主站断网不会导致新模式下的子站授权租约到期。

速率和在线连接复用子站约 5 秒的内存采样，样本过期或核心未提供计数时显示未知。累计流量来自子站持久化计量。主站不将不同子站的同名用户自动合并，也不替换子站数据库；统一账号和全局配额的旧协议见[兼容说明](BUSINESS-SITES-LEGACY.md)。本版本调度不包含自动跨站负载均衡或故障切换。

## 升级现有连接

- 原“独立面板接入”记录自动进入统一列表，离线也能迁移。迁移只更新主站目录，不改变远端角色、不重启远端。
- 已使用拉取式业务协议的站点保留在同一列表，通过“权限调度”维护。移除后立即隐藏，后台保留计量水位和配额预留，等待旧授权撤销确认。
- 旧业务子站升级到 0.24.0 后可生成并导入新令牌，转为本地数据管理。转换保存最后有效的节点权限，停止旧策略拉取，并通过受控重启生效；旧主站中的拉取记录可直接移除。
- 旧网关可继续通过 `gyp_` 令牌管理已有接口；完整服务启停、在线汇总及新权限接口需要子站升级到 0.24.0。只读历史令牌保持只读，不能调度；重新导入管理令牌后启用调度。

## 凭据和数据边界

令牌只在生成时显示，主站加密保存，列表不返回原始凭据。网关绑定令牌创建者并校验权限、到期时间及目标身份。普通用户无法导入、控制或查看远程站点管理数据。子站的备份、密码、站内信、资金业务和配对令牌管理在本地执行；网关不允许递归转发或导出恢复密钥。

备份子站时保留完整状态目录（包括 `site-local.json` 转换标记）、配置和密钥。Lite／Pro 安装、升级和回滚流程见[版本指南](EDITIONS.md)与[运维指南](OPERATIONS.md)。
