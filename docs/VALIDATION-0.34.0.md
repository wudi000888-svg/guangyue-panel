# 0.34.0 验收记录

本记录对应用户中心、可配置侧边栏、客户端中继和国家访问限制的实现。本地 UI 测试使用合成账号与套餐，不连接生产数据库。GitHub 安装测试与发布部署结果以相应 Actions 和 Release 为准。

## 本地验证

- Go 全模块 race 测试、go vet 通过；govulncheck 未发现代码可达漏洞。
- 前端 18 个测试文件、67 项测试通过，英文目录 2982 条，类型检查与生产构建通过。
- 部署与更新器 36 项测试通过（使用 OpenSSL 3）。
- 26 个客户端下载链接均在官方固定版本 Release 或官方商店验证；嵌入目录与前端源一致。
- DB-IP 数据库、许可 hash 和 SPDX 许可集成验证通过；版本及发布树检查通过。

## 浏览器验证

- 1024×600 与 390×600：更新窗口展开手动选版与回退后仍在视口内；下部可滚动，回退选择进入正确确认界面。手机关闭弹窗后焦点恢复到打开导航按钮。
- 侧边栏勾选保存后即时更新；未选功能可从系统设置的更多功能目录进入。
- 成员设置不挂载管理员设置组件，后端设置写入仍要求 owner 权限。
- 用户中心在手机和 1366×768 桌面显示当前套餐、剩余流量和天数、套餐队列及服务快捷入口，无横向溢出。
- 客户端架构选择保留原始下载索引；中继开启时主链接访问本站，官方下载入口继续可用。远程子站上下文使用官方直链。
- 禁止访问页面显示规则原因、请求 IP、国家和数据库来源，无账户内容或弹窗残留；规则解除后重新检测恢复用户中心。
- 选中当前位置并开启国家限制时，保存需要管理员先确认管理方式，防止误操作。

## 使用范围

客户端下载中继与国家限制默认关闭。国家限制作用于浏览器面板访问，不影响代理流量、订阅链接和现有认证的机器接口。国家归属由本地 DB-IP Lite 数据判断，未知国家不匹配黑名单；额外 CDN 必须正确还原真实地址。见 [访问管理](SITE-ACCESS.md) 与 [客户端下载](CLIENT-DOWNLOADS.md)。
