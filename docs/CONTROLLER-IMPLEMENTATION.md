# 0.16.0：主控与业务站历史实施记录

本文归档 0.16.0 的主动拉取式业务站设计，不是当前子站接入步骤。该设计让轻量业务站通过 HTTPS 拉取配置、使用本地 SQLite 与独立密钥，不依赖远端 PostgreSQL / Redis。历史部署维护见 [旧业务站说明](BUSINESS-SITES-LEGACY.md)。

当前 Pro 在 **群站管理** 中直接导入子站令牌，独立站与子站接入已统一；无需注册文件、预建分组或另设联邦入口。子站保留本地管理与独立运行能力，流程见 [子站指南](BUSINESS-SITES.md)。

## 当时的数据与执行边界

- 主控维护用户、出口资源、业务站分组、资源分配、节点模板和统一订阅。
- 业务站保留独立 TLS / Reality 私钥、SQLite、配置版本和流量检查点，仅接收获授权的代理凭据与出口。
- 每站点保留 VLESS / HY2 默认直连节点；绑定出口创建附加节点，不替换默认节点。
- 当时有限总配额按业务站预分配，未消费额度占用总余额，离线站点不自动重分配；流量上报单调且幂等。后续版本已调整预算与授权约束，当前规则见 [套餐与计量](PLANS.md)。
- 配置有授权有效期，业务站在短暂断连时使用最近生效配置，到期停止授权；不保证断网期间即时撤销。
- 全局出口支持独占/共享，资源更新按需下发；各业务站独立检测链路，业务节点不自动更换出口。
- 同站点同出口的节点共享质量报告与标签，协议测速独立。出口变化或报告过期后重新检测。
- Release 分别提供 Lite、Pro 安装包；Pro 包支持主控与业务站，包内标记决定默认安装角色。
