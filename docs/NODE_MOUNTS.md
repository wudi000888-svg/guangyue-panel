# 子站节点挂载与 IP 桥接

## 两种子站出口

Pro 支持让主站套餐使用子站资源。先选择需要的流量路径，再连接和授权：

- **子站节点**：在左侧“本地节点”下方进入。挂载后订阅直接返回子站的 VLESS/HY2 地址，客户端直连子站，流量不经过主站；这些节点自动加入默认子站节点组，不会进入本地或公共节点组。
- **子站 IP 池**：在“本地 IP 池 → 子站 IP 池”进入。主站创建加密桥接出口，客户端连接主站并由主站中转，最终使用子站 IP 作为出口；创建出的资源属于主站本地出口，可在本地节点配置中选择，不能作为子站直连节点使用。

子站节点不会进入本地节点组；子站 IP 池也不会出现在子站节点挂载列表。成员只导入当前套餐提供的订阅，不需要理解不同来源或“混合订阅”选项。管理员可以检查各来源的授权结果。

主站使用 Pro，子站可为 Lite 或 Pro。双方都需支持当前挂载、计量和权限接口；新部署建议使用相同正式版本。历史挂载协议自 0.25.0 引入，并不表示旧版支持此后所有功能。

## 使用

1. 子站管理员在“配对令牌”生成管理令牌，可永久有效；在该令牌的“节点共享”中控制共享范围或暂停共享。
2. Pro 在左侧“子站节点”导入令牌，进入选节点页面；“子站管理与调度”保留同一节点池的入口。连接本身不自动挂载节点。
3. 勾选需要的共享节点，无需再点“加入挂载列表”。列表分别显示协议、所属站点、接入域名、出口 IP、倍率和主站节点组；同名的 VLESS/HY2 分别勾选。所有挂载节点自动进入“默认子站节点组”，无需选择分组。展开节点设置可改别名或启停，取消勾选即可卸载。保存后显示进度与结果，并刷新节点组成员。
4. 点击 **保存挂载**，查看进度与结果。当前套餐允许这些节点时，系统同步主站成员的子站权限与预算，无需另外选择用户。套餐若只选择子站组内部分节点，新挂载的其他节点不会自动获授权。需要改节点范围时编辑套餐；需要改用户额度或有效期时到 **用户管理 → 套餐与权益**。
5. 成员在 **用户中心／我的订阅** 更新客户端订阅，获取当前套餐允许且已确认授权的节点。挂载节点带有 `[挂载·站点名称]` 标识。

挂载保存统一按套餐自动同步，用户列表和挂载页面没有单独分配节点入口。历史手动挂载记录在升级时转换，保留必要额度记录，但不能以独立配置覆盖当前套餐授权。

默认子站节点组初始为空；管理员套餐包含该组，演示套餐默认只包含本地节点组。保存挂载后，符合套餐权限的用户自动获得节点。

编辑套餐的节点组、组内节点、套餐专属倍率或协议开关，会同步当前生效成员并唤醒子站同步；额度、有效期、订单价格和排队套餐保留原快照。服务端只输出已确认的子站授权，客户端仍需刷新订阅。停用或卸载挂载节点立即停止分发，子站授权随同步撤回。详见[套餐规则](PLANS.md)。

客户端连接子站原有的 VLESS/HY2 接入地址，使用子站签发的用户专属凭据，沿用该节点原有出口。主站不添加本地代理入口、不以子站 IP 代替节点配置。订阅名称在原始链接、Base64 和 Mihomo 中统一带 `[挂载·站点名称]`。

每站最多选择 64 个节点、256 个用户，节点数与用户数之积不超过 4096。子站默认允许管理令牌共享全部节点，但主站仍须逐项挂载与授权；子站可收窄共享列表。每个主站绑定使用独立令牌。

## 权限与独立运营

本地节点组、公共节点组、子站节点组分别管理相应来源；套餐可以同时包含多种节点组。套餐未包含子站组时不会获得挂载节点；在子站组内选择单独节点时，仅授权所选节点。不同子站的同名节点独立选择。

子站为外来用户创建独立内部 ID 的代理身份，不覆盖本地同编号或同名用户。该身份不出现在日常用户管理列表（仍在监控与计量中保留），禁止面板登录和本地套餐改额；子站管理员删除该身份时实际永久停用并保留计量，不会被主站下次同步自动重建。暂停共享和撤销令牌只收回相应外来权限；站点整体“暂停服务”仍影响该站所有代理用户。

永久令牌与访问租约分开：主站约每 30 秒同步一次，授权最长 300 秒。正常运行时子站每 5 秒检查状态；核心进程的独立守护在租约到期后留出 6 秒同步宽限，再结束含过期授权的核心进程。原生部署由 systemd、Docker 部署由受管运行器，以保留本地身份、移除过期挂载身份的配置重新启动。进程退出最多另需 12 秒，正常守护条件下到期撤销约在 20 秒内完成。VLESS/HY2 旧连接撤销可能造成本地连接短暂重连；不会长期停止本地站点。HY2 新连接本来就需要本地面板认证，面板停机时须先恢复面板。

订阅只输出已经确认的缓存授权，不在用户刷新订阅时跨站访问。临时断联保留有效租约内的已确认配置；不分发未经确认的新授权。主站卸载或禁用节点后立即停止分发，远端不可达时显示待确认，客户端保存的旧链接由子站租约约束。

## 配额与结算

自动模式按主站用户剩余配额、可访问的挂载子站数量及是否有本地节点，自动计算预算；本地有可用节点时也保留一份。站点配置额度可以高于用户剩余额度，运行时只按用户实际剩余配额下发授权，额度耗尽后自动撤销该用户在站点的节点订阅。其他站点已发放或尚未结算的额度不重复分配。预算消耗过半后按剩余总额补充，减少无意义的配置更新；新站加入或额度变化时通过同步逐步调整。有限配额不会因可分配预算为零而变成不限量。不限量用户沿用不限量授权。

每个子站还可以设置共享月度预算和冷却时长。累计流量达到预算后，主站停止向所有成员订阅分发该子站节点，并在下一次同步撤销子站授权；节点仍保留在原节点组中。冷却到期后自动清零该子站共享用量，挂载同步重新下发授权和订阅，默认冷却 24 小时，最长 365 天。

主站只对已经下发且尚未确认结算的子站额度做运行时占用，本地节点不会因为尚未下发的站点配置而被提前扣减。用量在子站实际节点上采集，主站按用户累计水位及节点倍率版本校验差额并入账，不重复乘倍率。历史倍率不可重写，确认过的细目不再反复全量传输。对子站账本回滚到主站已确认水位之前的情况，拒绝下发新授权。

卸载全部节点同时撤回站点成员预算；未收到最终用量前，已下发预算仍被预留。套餐周期重置会先撤回所有子站授权并结算，再开始新周期。

移除子站保留未结算账本；“等待结算的已移除子站”显示尚未释放的连接。更换令牌建立新的隔离绑定，原连接退出分发并保留账本和预留额度。**先卸载并同步完成，再撤销旧令牌**，可避免无法取得最终水位。若子站永久丢失或令牌已撤销，系统不会猜测最终用量或自动释放尚有风险的额度。需要恢复原连接/账本完成结算。

流量核心采用采样计量，节点速率与短暂采样延迟仍受现有计量机制约束。异常终止核心可能失去最后一次采样后的内存计数；独立租约守护旨在阻止继续使用过期授权，不能恢复已经丢失的核心内存统计。

## 订阅地址与历史兼容

成员只有按当前套餐授权的订阅入口，不展示组或来源切换；管理员可检查不同来源。管理员选择来源后，节点列表、下载地址与二维码使用相同范围，协议筛选继续生效。

当前 `/sub/<token>` 不带 `source` 时也按套餐统一输出获授权来源；成员的来源参数强制按统一套餐范围处理，不能借参数扩大权限。管理员可显式检查各来源，或使用 `source=all` 查看获授权来源。旧 `/public-sub/<user>/<token>` 始终只输出公共节点，任何查询参数均不能扩大其权限。旧 `#/public-subscription` 书签进入同一页面并选择公共来源。公共代理采集、检测、黑名单与节点池保持可用。

“重置订阅地址”统一轮换普通/公共订阅凭据，所有旧地址失效，已导入的节点凭据仍有效；“撤销全部旧配置”还轮换代理凭据并向挂载子站同步撤销。

## 验证

后端包含令牌绑定、同编号身份隔离、精确节点允许列表、缓存订阅范围、倍率与周期结算、重复确认、离线移除、账本回滚防护和进程租约守护回归。CI 在 PostgreSQL 与 Redis 上执行集成检查。Lite/Pro 安装测试通过真实 Reality/HY2 客户端验证 TCP/UDP、计量、卸载与令牌撤销、已建立连接断开，以及面板进程停止时的核心租约守护和本地 Reality 用户继续连接。
