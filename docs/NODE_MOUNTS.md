# 子站节点池与订阅管理

从 0.25.0 起，Pro 可把令牌子站的真实节点挂载给主站用户。主站和子站均需升级到 0.25.0 或更新版本。

## 使用

1. 子站管理员在“配对令牌”生成管理令牌，可永久有效；在该令牌的“节点共享”中控制共享范围或暂停共享。
2. Pro 在“私有 IP 池 → 子站 IP 池”导入令牌，即可进入选节点页面；“群站管理”保留同一节点池的管理入口。连接本身不自动挂载节点。
3. 勾选需要的共享节点，无需再点“加入挂载列表”。列表分别显示协议、所属站点、接入域名、出口 IP、倍率和主站节点组；同名的 VLESS/HY2 分别勾选。“默认子站节点组”在新安装和升级时预置为空，新选择默认加入此组；已保存的挂载分组保持原样。组被停用时不预选。展开节点的高级设置可改分组、别名或启停，取消勾选即可卸载。
4. 点击 **保存并分配用户**，选择主站用户，预览权限变化后确认即可，无需创建套餐。也可只保存挂载，稍后在 **用户管理 → 分配节点** 操作。新挂载默认按主站节点组自动授权；权限变化在后续同步中更新子站授权，无需逐个填写子站预算。组内节点共享权限，因此分配一个组会开放该组内所有获允许的节点。
5. 用户在“订阅管理”选择全部节点或子站挂载节点，再复制订阅地址。节点仍带有 `[挂载·站点名称]` 标识。

0.26.0 以前保存的手动用户/额度配置继续保留，可在“高级分配设置”切换为自动分配；也可继续手动指定成员和每位用户的子站预算。主站升级到 0.26.0 即可使用自动分配，子站保持 0.25.0+ 的挂载协议兼容。

默认组不含节点，也不自动加入任何用户或套餐。必须同时完成挂载与用户/套餐授权才会开放访问。

0.27.0 起主站支持上述直接分配流程，子站仍兼容 0.25.0+。**子站 IP 池 → 查看节点分组** 可按来源筛选，按站点、节点、协议或 IP 搜索。直接分配仅修改节点权限，保留现有额度、有效期、协议开关、套餐和凭据。批量分配默认追加，单用户可精确替换或恢复套餐/默认权限；取消全部组表示无节点权限。

客户端连接子站原有的 VLESS/HY2 接入地址，使用子站签发的用户专属凭据，沿用该节点原有出口。主站不添加本地代理入口、不以子站 IP 代替节点配置。订阅名称在原始链接、Base64 和 Mihomo 中统一带 `[挂载·站点名称]`。

每站最多选择 64 个节点、256 个用户，节点数与用户数之积不超过 4096。子站默认允许管理令牌共享全部节点，但主站仍须逐项挂载与授权；子站可收窄共享列表。每个主站绑定使用独立令牌。

## 权限与独立运营

节点组可混合本站、公共、挂载节点。原有组 ID、启用状态和成员权限保留，历史 `scope` 字段只作为兼容数据，不再限制可加入的节点来源。未选组的挂载不会通过子站默认组获得权限。

子站为外来用户创建独立内部 ID 的代理身份，不覆盖本地同编号或同名用户。该身份不出现在日常用户管理列表（仍在监控与计量中保留），禁止面板登录和本地套餐改额；子站管理员删除该身份时实际永久停用并保留计量，不会被主站下次同步自动重建。暂停共享和撤销令牌只收回相应外来权限；站点整体“暂停服务”仍影响该站所有代理用户。

永久令牌与访问租约分开：主站约每 30 秒同步一次，授权最长 300 秒。正常运行时子站每 5 秒检查状态；核心进程的独立守护在租约到期后留出 6 秒同步宽限，再结束含过期授权的核心进程。systemd 会以保留本地身份、移除过期挂载身份的配置重新启动。进程退出最多另需 12 秒，正常守护条件下到期撤销约在 20 秒内完成。VLESS/HY2 旧连接撤销可能造成本地连接短暂重连；不会长期停止本地站点。HY2 新连接本来就需要本地面板认证，面板停机时须先恢复面板。

订阅只输出已经确认的缓存授权，不在用户刷新订阅时跨站访问。临时断联保留有效租约内的已确认配置；不分发未经确认的新授权。主站卸载或禁用节点后立即停止分发，远端不可达时显示待确认，客户端保存的旧链接由子站租约约束。

## 配额与结算

自动模式按主站用户剩余配额、可访问的挂载子站数量及是否有本地节点，自动计算预算；本地有可用节点时也保留一份。其他站点已发放或尚未结算的额度不重复分配。预算消耗过半后按剩余总额补充，减少无意义的配置更新；新站加入或额度变化时通过同步逐步调整。有限配额不会因可分配预算为零而变成不限量。不限量用户沿用不限量授权。

手动模式保留每用户固定预算。两种模式均在主站预留分给各子站的额度，本地只使用剩余配额。用量在子站实际节点上采集，主站按用户累计水位及节点倍率版本校验差额并入账，不重复乘倍率。历史倍率不可重写，确认过的细目不再反复全量传输。对子站账本回滚到主站已确认水位之前的情况，拒绝下发新授权。

“剩余子站预算”表示从当前已确认用量起还可使用的额度，提交相同额度不会重置周期预算。管理员显式修改预算会更新之后的周期预算。卸载全部节点同时撤回站点成员预算；未收到最终用量前，已下发预算仍被预留。套餐周期重置会先撤回所有子站授权并结算，再开始新周期。

移除子站保留未结算账本；“等待结算的已移除子站”显示尚未释放的连接。更换令牌建立新的隔离绑定，原连接退出分发并保留账本和预留额度。**先卸载并同步完成，再撤销旧令牌**，可避免无法取得最终水位。若子站永久丢失或令牌已撤销，系统不会猜测最终用量或自动释放尚有风险的额度。需要恢复原连接/账本完成结算。

流量核心采用采样计量，节点速率与短暂采样延迟仍受现有计量机制约束。异常终止核心可能失去最后一次采样后的内存计数；独立租约守护旨在阻止继续使用过期授权，不能恢复已经丢失的核心内存统计。

## 订阅兼容

“订阅管理”统一展示全部、本站、公共、子站挂载来源。来源选择会更新节点列表、下载地址与二维码；客户端地址中的 `source` 明确保存选择。协议筛选仍生效。

旧 `/sub/<token>` 不含 `source` 时保持原普通节点范围。新统一地址使用 `source=all`。旧 `/public-sub/<user>/<token>` 始终只输出公共节点，任何查询参数均不能扩大其权限。旧 `#/public-subscription` 书签进入同一页面并选择公共来源。公共代理采集、检测、黑名单与节点池保持可用。

“重置订阅地址”统一轮换普通/公共订阅凭据，所有旧地址失效，已导入的节点凭据仍有效；“撤销全部旧配置”还轮换代理凭据并向挂载子站同步撤销。

## 验证

后端包含令牌绑定、同编号身份隔离、精确节点允许列表、缓存订阅范围、倍率与周期结算、重复确认、离线移除、账本回滚防护和进程租约守护回归。CI 在 PostgreSQL 与 Redis 上执行集成检查。Lite/Pro 安装测试通过真实 Reality/HY2 客户端验证 TCP/UDP、计量、卸载与令牌撤销、已建立连接断开，以及面板进程停止时的核心租约守护和本地 Reality 用户继续连接。
