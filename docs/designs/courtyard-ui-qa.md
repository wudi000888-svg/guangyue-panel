# 0.33.0 月庭 UI UX 验收记录

## 环境与范围

本机 Penpot 2.17.2 用于原生设计。产品验收使用本地 Vite 与隔离的进程内 API 数据，覆盖 Pro 管理员、成员与未登录状态；站点、账号、余额、订单、订阅均为测试数据。没有执行生产支付、退款或线上部署。模拟 API 只用于检查交互呈现；真实权限、订单开通和安装行为由后端测试及 Linux CI 检查。

## 设计交付

[原生可编辑文件](penpot/guangyue-mooncourt-v0.33.0.penpot) 已从 Penpot 界面实际导出，可直接导入编辑。文件包含 5 页、63 顶层画板（桌面 31、手机 31、基础 1）、颜色 Token、2 个按钮组件、201 个同页有效跳转与 5 个流程。跨页面管理模块使用 Penpot 页面列表切换。

[结构审计](penpot/audit.json) 与 [文件清单](penpot/manifest.json) 确认 ZIP 完整性、交互目标有效、父按钮与内文字一致、流程起点属于对应页面；没有画板重叠或小于 12px 的文本。原生文件也经过浏览器目视检查。设计中的节点、用量和订单是示例，不能作为真实运行状态。

## 产品交互验收

- 登录：原创庭院图、品牌文字、桌面双栏与手机单栏、密码显示控制与注册入口。注册后端拼图验证规则保留，不改为只依赖前端的简单滑块。
- 管理员：工作台、套餐、成员、节点、子站、IP 池、实时监控、设置、任务、配对令牌和运维界面检查。Lite 导航与搜索复用实际允许路由，隐藏无权限 Pro 入口。
- 子站挂载：取消香港 HY2 节点并保存，成功提示立即出现，节点总数 6→5、香港节点 2→1，列表和节点组更新；再次挂载恢复为 6。保存与后续目录刷新失败分开提示，保留重试。
- 套餐：展开默认子站组可看到对应子站 6 个节点，在组内选择单独节点。所选节点暂未出现在目录时，保留选择并明确提示，不扩大为整组授权。
- 出口衔接：新建节点设置倍率 2×→添加出口→保存，自动返回节点编辑，新增 SOCKS5 出口已选中，原倍率仍为 2×；取消新增出口或 Escape 返回节点草稿。另模拟保存后一次 503 刷新失败，保存回包同步出口资料，返回时仍显示新增出口与 3× 草稿。验收写入只进入模拟 API 内存。
- 成员服务：首页显示当前套餐、39GB/200GB 用量、剩余 20 天和待恢复套餐 12 天；手机“开始连接”位于套餐名下首屏。会员页面不展示节点组或混合订阅术语。
- 连接引导：设备→客户端→导入；macOS 要求选择 Apple Silicon 或 Intel，Apple 分支指向 aarch64.dmg 官方发布资产；二维码正常生成。订阅格式、协议、节点质量与手动连接入口保留。
- 订单：选择零价套餐生成新订单并进入确认页；明确显示 0 元，点击“确认免费开通”后按 API 返回的 completed 状态显示生效。pending 与 provisioning 不提前显示成功。模拟状态变化不作为真实开通验证。
- 历史订单：后端回归检查首批 50 条以外的旧订单、成员不能读取别人的订单、管理员范围及不存在 ID。工单携带成员身份进入精确订单详情，显示加载、错误与重试。
- 工单：手机列表→单独会话→输入回复草稿→返回列表→再次进入，未发送草稿仍保留；回复、附件、历史分页、管理员备注和关联信息入口保留。
- 响应式：390×844、375×812 的服务页面（含英文和暗色）文档宽度等于视口，没有横向溢出；390×844 子站页面同样无横向溢出。底栏不遮挡主要操作。
- 可读性：正文及共享标签最低 12px、主要手机操作目标 44px。检查正文对比度 12.86:1，浅/深辅助字 4.80/6.86:1，浅/深主按钮 6.39/9.04:1，侧栏焦点 6.77:1；状态使用文字与颜色共同表达。
