# 0.32.0 庭院界面验收记录

## 验收环境

浏览器连接本地 Vite 预览和隔离的内存 API 数据，分别模拟 Pro 管理员、成员和未登录状态。站点地址、账号、余额、订单、订阅凭据均为测试数据；未连接生产 API，也没有执行真实支付、退款或权限变更。

## 已验证行为

- 桌面主要页面：总览、套餐、节点组、本地节点、子站节点、用户、任务、实时监控、设置、子站管理、本地 IP 池、配对令牌、运维状态正常呈现；页面没有横向溢出。
- 手机视口 390 × 844 与 375 × 812：子站状态卡片、挂载弹窗、设置分类和保存条，以及成员订阅、商店、订单、钱包、客户端、工单正常呈现。保存条避开底部常用导航。
- 挂载：取消一个已挂载节点后出现未保存提示；保存后立即出现成功反馈，已选节点数、节点组数据及子站列表数量同步更新。
- 套餐：组内选择继续使用包含站点身份的独立节点键；保存成功提示和模板版本即时更新；既有权益更新方式保留。
- 订单：从本地零价套餐创建订单后进入订单中心，新订单显示单号、状态和价格。支付、退款审批按钮保留，未执行真实交易。
- 工单：状态与搜索筛选、详情、回复提交成功提示及回复历史均验证；图片上传、关联资源与管理员备注入口保留。
- 登录：桌面双栏庭院图与表单、手机单列表单、密码可见切换和注册入口验证。验证码服务端规则保持原实现。
- 导航：手机抽屉、键盘搜索、上下选择与 Enter 跳转、桌面折叠导航验证；导航仅重新组织已有授权入口，不增加权限。
- 浅色与深色均检查；语义正文与主按钮颜色对比度检查达到 4.5:1。状态同时显示文字，不仅使用颜色。

## 自动检查

- 前端 Vitest：13 个文件、41 项测试通过，包括权限入口保留、导航顺序与搜索回归。
- English catalogue：2613 条静态界面文案覆盖。
- Vue TypeScript 检查与 Vite 生产构建通过。
- 部署 Python 单元测试：36 项通过。macOS 验收使用随工作环境提供的 OpenSSL 3 及其配置，避免系统 LibreSSL 不支持测试选项。
- 版本一致性、发布树检查与 Git 空白检查通过。

Linux CI 另行检查 Go race/vet、数据库与 Redis、漏洞与密钥扫描、协议核心构建，以及六种安装/升级/回滚组合。正式安装包只使用该 CI 构建产物。

## 设计源与边界

设计规范及 Token 在本目录维护，可用于 Penpot Library；本次未连接在线 Penpot 服务。视觉素材保留仓库内 SVG。前端共用主题与主壳样式由 main.ts 按明确顺序引入；旧侧栏规则限定到 grouped-nav，避免影响页面工具栏。
