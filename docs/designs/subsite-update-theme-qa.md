# 0.39.17 子站更新与主题验收

本轮使用实际 Vue 应用及隔离示例 API 检查子站工作区、成员中心和亮色导航，未执行生产服务器安装、回退或支付操作。服务器诊断只读取服务与更新状态，并在子站执行一次正式版本源检查。

- 真实子站原检查时间过期、目录为空，显式检查后成功读取 0.39.16 等正式版本，确认问题是主站读取缓存而非发布源不可达。
- 实际应用展开版本管理后出现可用更新与回退选项；390px 手机版本控件纵向排列，页面和成员中心文档宽度等于视口，无横向溢出。
- 亮色顶栏标题、语言选择、账户文字、侧栏、版本徽标与内容辅助文字目视可读。正文、状态、输入边界及庭院壁纸合成色通过 9 项对比度回归；小文字最低 4.5:1，启用控件边界最低 3:1。
- 更新提交、重启失联、不同操作回执、超时、同编号重试、冲突拒绝和页面销毁由隔离 API 回归验证；只有匹配回执成功且运行版本一致才完成。真实主站管理令牌到子站 API 与本机更新器的检查、提交、冲突响应由 Go 集成测试覆盖。
- 本地前端全套 251 项测试、类型检查、生产构建、Go 全包 race 和 vet 通过。Python 70 项中 68 项在本机通过，两个证书测试受 macOS LibreSSL 缺少 `x509 -checkhost` 限制，完整 Linux CI 验证作为发布前置条件。

正式安装、升级、回退及 PostgreSQL/Redis 验证使用 GitHub Linux CI 产物；版本说明见 [更新文档](../UPDATES.md)。
