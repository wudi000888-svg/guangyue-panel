# 钱包永久删除、资产卡片与实时 Gas

本轮将钱包作为独立资产账户展示。桌面按钱包展示瀑布卡片，移动端单列，卡片仍按 DOM 顺序供键盘与辅助技术阅读。卡片直接显示支持网络、USDT/USDC、原生手续费余额、有余额地址数和查询状态，收款、Gas、归集、活动一步进入对应钱包详情。按链独立汇总完整历史地址，查询失败保留已知数值，未知数值使用横线。

## 永久删除

删除验证管理员当前密码、钱包版本及新版专用的不可撤销确认，钱包实体和加密助记词会从面板数据库清除。只带旧版可恢复删除确认的请求在事务前被拒绝。新收款配置随事务解绑。升级时清理旧版已软删除的钱包。历史地址、订单、链上交易去重、nonce 与资金任务记录保留公开的最小归属；这些记录没有可供恢复的密钥，也没有已删除钱包列表或撤销入口。

已永久删除的原钱包 ID 不能通过面板的钱包备份恢复。管理员保管的外部助记词和独立备份仍由管理员掌握；面板不会擦除离线文件或操作系统级整机快照。删除不会自动移动链上资金，没有外部恢复材料可能失去后续提取能力。未结束的资金任务须先解决，防止删除签名材料后遗留不明交易。

明确导入助记词会创建新钱包 ID，使用标准 Wallet Core 派生及后端独立核验。导入后保持暂停，先核对历史索引和备份。本站同分支的历史最高索引作为硬下限，原地址不会再分配给新订单；同分支历史地址仍可用于资产查询和明确批准的归集，原订单归属和链上事件唯一键保持稳定。

## 5 秒费用查询

独立只读 Gas 接口提供参考价、原生币转账参考费、资金地址余额、区块与查询时间，接口链参数使用配置 slug（如 `ethereum`、`bsc`）。后台短期单飞缓存不超过 4 秒，页面可见时每 5 秒查询，切换上下文、隐藏或卸载后取消。

转账输入有效时，每 5 秒串行查询实际费用预估，不广播或补款。查询较慢时等待本次完成，避免大钱包产生重叠的地址扫描；独立 Gas 参考查询继续运行。点击核对后冻结钱包、网络、币种、收款地址和服务端密封报价，后台刷新不会替换正在确认的交易。过期或无效报价不能批准，最终转账仍验证密码、预算、余额、nonce 和链上收据。

链上出块与最终性进度不受前端刷新频率控制。大地址集预估可能超过 5 秒，界面显示正在估算及上次查询时间，不将旧快照伪装为实时结果。

验收使用合成钱包、隔离 RPC 与示例余额，覆盖多钱包、长名称、手机、深浅主题、创建和删除即时反馈、历史地址高水位、备份拒绝复活、费用冻结、取消与生命周期。工程测试不使用真实钱包或广播主网交易。
