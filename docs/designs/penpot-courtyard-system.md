# 广月面板 · Penpot 中式庭院视觉系统

这份规范是前端重构的设计源，适合在 Penpot 中建立为共享 Library。画板素材位于 `frontend/public/guangyue-courtyard.svg`，可直接导入 Penpot 作为广州塔、月亮、屋檐和月色庭院的视觉基底。

## 设计目标

- 让登录页先传达“夜色、庭院、可信赖的控制台”，进入系统后仍保持高信息密度和清晰的操作层级。
- 管理员页面使用纸张色卡片承载表格与运维信息，用户页面使用更轻的订阅、套餐和流量卡片。
- 侧栏保留所有现有路由与权限隐藏规则，移动端保留底部常用导航和抽屉式完整导航。
- 颜色、间距、圆角、焦点态和触控尺寸均由同一组 Token 控制，浅色和深色模式只替换 Token。

| Token | 浅色 | 深色 | 用途 |

| `canvas` | `#F3EEE5` | `#101B1F` | 页面底色 |
| `surface` | `#FFFAF2` | `#17282C` | 卡片、表格、弹窗 |
| `surface-raised` | `#F8F1E6` | `#1D3336` | 表头、次级容器 |

| `border` | `#E2D5C3` | `#31504D` | 分割线、边框 |

## 组件与状态

1. **Gateway / 登录**：深青夜色背景、月亮光晕、广州塔剪影；登录卡片保持单列，输入框高度 42px，主按钮高度 47px，错误提示使用朱砂色。
2. **Navigation / 侧栏**：暗色夜门，品牌月亮图标，当前项使用玉色左边框；公共功能使用金色区分，不改变权限。
3. **Page heading / 页面标题**：恢复标题与描述的视觉层级；桌面端标题 30px，移动端 23px，操作按钮与标题同一行或自动换行。
4. **Metric card / 指标卡**：纸张色卡片、底部短色条、轻阴影；不改动任何指标计算。
5. **Table / 表格**：桌面端保持横向表格，移动端转换为双列信息卡；触控按钮最小 44px。
6. **Overlay / 弹窗**：深色遮罩、10px 背景模糊、20px 圆角；保留原焦点陷阱与 Escape 关闭。
7. **Mobile shell / 移动壳**：顶部栏、抽屉导航、底部常用导航与安全区适配保持现有逻辑，视觉改为半透明纸张和玉色选中态。

## 实现映射

- Token 与组件样式：`frontend/src/penpot-theme.css`
- 登录、桌面壳、移动壳：`frontend/src/App.vue` 的现有结构与 `penpot-theme.css` 覆盖层
- 仪表盘与业务页面：继续使用原路由、API、组件和响应式 class，主题层统一替换视觉表达
- SVG 画板：`frontend/public/guangyue-courtyard.svg`

任何新增页面都应优先复用这些 Token 和组件状态，避免重新引入独立颜色、阴影或断点。
