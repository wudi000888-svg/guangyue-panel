# 广月面板 · 庭院界面系统（0.32）

设计源由本目录的 `penpot-tokens.json` 与前端组件共同维护，可用于 Penpot 共享 Library。广州塔、月亮、庭院的矢量素材位于 `frontend/public/guangyue-courtyard.svg`，可直接导入 Penpot；所有正式页面资源均本地提供，不依赖远程字体或图片服务。

## 视觉方向

用玉色、纸白和墨绿建立明确层级。庭院插画集中用于登录和仪表盘；表格、表单与操作按钮周围保留安静背景。去掉旧主题叠加的格纹、印章、斜线、重复大插画和重阴影，以文字、间距与状态表达优先级。

主界面正文使用系统无衬线字体；书卷感宋体仅用于登录与庭院标题。默认正文 14px，说明 12–13px，页面标题 26px（手机 23px），指标数字 25–30px。数值使用等宽数字，关键数据不依赖颜色传递。

## 信息与操作层级

- 导航按业务用途分组，所有已授权页面保留；功能搜索支持中文、英文和键盘快捷键。成员与管理员仅显示各自有权限的功能。
- 顶栏提供当前位置、搜索、账号和显示设置。远程站点始终有独立上下文提示，避免把子站当作主站操作。
- 仪表盘先呈现核心指标、常用入口，再展示流量趋势、服务状态和待处理事项。图表保留数据表入口和键盘可用性。
- 成员端优先展示当前套餐、剩余天数、额度与订阅入口。技术性节点组与混合订阅管理仍留在管理员视图。
- 子站用状态卡片表达在线、暂停、异常和预算；搜索与状态筛选用于定位站点。挂载编辑必须展示保存中、成功和失败状态。
- 系统设置按站点、账户服务、运行网络分类；切换分类保留本次未保存输入，保存按钮在移动端避开底部导航。
- 套餐编辑按基本信息、价格有效期、节点协议分段。价格、额度与节点权限仍由原后端校验。

## 响应式与无障碍

桌面操作按钮至少 40px；手机操作目标至少 44px，输入字号至少 16px，避免浏览器自动放大。650px 以下详情堆叠为单列；主壳在 900px 切换完整导航抽屉与常用底栏。表格保持已有卡片替代或容器内横向滚动，不能把数据列直接删掉。

可见键盘焦点、搜索对话框焦点管理、Escape 关闭、跳到内容、`aria-busy`、状态播报与明确空状态均是组件要求。尊重 `prefers-reduced-motion`；不以全页背景模糊、无限动画或远程字体交换可读性。

## 实现边界

- `frontend/src/penpot-theme.css`：全局语义色、控件、卡片、表格、反馈与庭院标题。
- `frontend/src/shell-ui.css`：导航、登录、移动端壳与搜索。
- `frontend/src/styles/member-ui.css`：成员页面共用排版和操作样式。
- 各页面保留自己的布局与业务交互；新增规则应优先使用共享 Token，不再追加一套覆盖全站的主题文件。

API、路由、权限、套餐计费与退款审核流程保持完整。界面预览使用隔离本地环境与测试数据，不将预览数据写入生产站点。
