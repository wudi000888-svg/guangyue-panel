# 0.15.0 单机版与 Pro 实施记录

提供低内存 Lite 单机版和基于 PostgreSQL / Redis 的 Pro 版，为多 VPS 群站扩展建立边界。项目主许可为 LGPL-3.0-only，保留既有与第三方版权声明。

## 架构决策

- 共用业务规则、代理协议和 UI，edition 区分资源与基础设施配置。Lite 使用 SQLite；Pro 使用 PostgreSQL 和 Redis。
- 站点是数据、密钥、任务、缓存和核心应用边界；Pro 中每个站点使用独立 PostgreSQL schema，控制器只操作其分配的站点。群站控制通过经过认证的管理协议访问各站点，禁止把多个站点配置应用到同一个本机核心。
- PostgreSQL 是持久化事实来源，Redis 提供短缓存；PostgreSQL 提供控制器独占租约；Redis 故障不能破坏持久化数据，失去控制租约时停止变更核心配置。
- 固定出口优先，默认不根据测速自动切换业务节点。公共与私有资源/订阅、简易与专业界面、normal 与 no_logs 保持独立。
- 核心包保留现有协议与路由行为，避免把 UI/存储改造变成协议重写。
